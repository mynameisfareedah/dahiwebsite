# Maintenance Guide

## Updating content

- Update site content in the data files under `src/data/`.
- Replace images in the project root or `public/` as needed.
- Keep alt text descriptive for public-facing images.

## Troubleshooting

- If images do not load, confirm the files exist in the project root or `public/`.
- If the dashboard fails to load, confirm Supabase environment variables are present.
- If the service worker causes stale assets, clear browser storage and refresh.
